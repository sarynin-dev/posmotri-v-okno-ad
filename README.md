# Проект «Посмотри в окно»

Ссылка на репозиторий: https://github.com/sarynin-dev/posmotri-v-okno-ad

## Описание

Одностраничное интерактивное веб-приложение «Посмотри в окно» с возможностью поиска и просмотра видеороликов из разных городов и в разное время суток. Проект выполнен по итогу третьего спринта курса «Фронтенд-разработчик» Яндекс Практикума.

## Что было сделано

В рамках практической работы была свёрстана и стилизована страница работающего приложения по макету:

- **Сетка и компоновка:**
  - Контейнер приложения отцентрирован по горизонтали и вертикали внутри экрана с помощью Flexbox.
  - Двухколоночный лейаут: левая секция (`.result`) с окном видеоплеера и формой фильтрации, правая секция (`.content__details`) с крупным акцентным заголовком и скроллируемым списком карточек.
  - Организованы пропорциональные отступы между всеми блоками и элементами через свойство `gap`.

- **Форма поиска и кастомные элементы управления:**
  - Текстовое поле ввода города со сбросом браузерных стилей (`appearance: none`), стилизацией плейсхолдера и верхне-нижней границей.
  - Кастомные квадратные чекбоксы фильтра времени суток («Утро», «День», «Ночь»), реализованные через псевдоэлемент `::after` при псевдоклассе `:checked`.
  - Улучшенная доступность и клавиатурная навигация: выделение обёртки лейбла при фокусе с клавиатуры с использованием современной связки псевдоклассов `:has(:focus-visible)`.
  - Интерактивное подчёркивание подписи чекбокса при наведении на любую точку активной зоны лейбла.

- **Карточки видео и интеграция с шаблонами:**
  - Стилизованы экземпляры карточек, создаваемые JavaScript-скриптом из тега `<template>`.
  - Для контейнера списка карточек задана фиксированная высота с кастомным скроллбаром (`::-webkit-scrollbar`).
  - Оформлены состояния карточек: текущая выбранная карточка (`.content__card-link_current`), состояние нажатия (`:active`), фокус (`:focus-visible`) и наведение (`:hover`).
  - Реализовано аккуратное ограничение текста: заголовок карточки обрезается троеточием (`text-overflow: ellipsis`), а текст описания ограничен четырьмя строками с помощью `-webkit-line-clamp`.

- **Кнопки и состояния:**
  - Базовые стили переиспользуемой кнопки `.button` и индивидуальные размеры для кнопки «Найти» в форме и кнопки «Показать ещё» в списке карточек.
  - Оформлены все интерактивные состояния: `:hover`, `:active`, `:focus`, `:focus-visible`.

- **Позиционирование и прелоадеры:**
  - Контекст позиционирования (`position: relative`) настроен у контейнеров видео и списка, что обеспечивает корректное отображение анимации прелоадера и блока с ошибкой.
  - Позиционирование `position: absolute` вынесено исключительно для утилитарного класса скрытия `.visually-hidden`.

- **Типографика и шрифты:**
  - Подключены шрифты гарнитур `Oswald` (700) и `Fira Sans Condensed` (400 и 700) в форматах `.woff` и `.woff2` с системными фолбэками `sans-serif`.
  - Для главного заголовка настроены брутальный интерлиньяж и контрастное выделение акцентной части слова.

## Использованные технологии

- Семантическая разметка HTML5 и теги шаблонизации `<template>`.
- Современные методы раскладки CSS3: Flexbox (`display: flex`, `gap`, `align-items`, `justify-content`).
- Продвинутые селекторы и псевдоклассы CSS: `:has()`, `:focus-visible`, `:checked`, `:not()`, псевдоэлементы `::after`.
- Кастомизация встроенных браузерных компонентов и скроллбара (`::-webkit-scrollbar`).
- Адаптация медиа-контента (`object-fit: cover`, `object-position: center`).
- Методология БЭМ для именования классов и модульной структуры стилей.

## Локальный запуск

Для просмотра проекта откройте файл `index.html` в любом современном браузере.
